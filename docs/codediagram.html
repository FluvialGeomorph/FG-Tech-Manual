Appendix C — Analysis Process and Tool Dependencies

Overview

This page provides a visual guide to the FluvialGeomorph toolbox analysis workflow, showing the order of operations and dependencies between tools.

How to Use
  • Hover over any tool card to see a description
  • Click on a tool card to view its source code on GitHub
  • Scroll horizontally within each phase to see all tools
  • Tools are organized by analysis phase from left to right

Interactive Workflow Diagram

Phase 1: Data Preparation & Critical Spatial Analysis

🤔 Critical Thinking Required

Before running tools, consider:

  1. Watershed Boundary Assessment
    • Does your watershed boundary accurately represent the hydrologic unit?
    • Are there edge effects or artifacts from the delineation process?
    • Do you need to buffer or expand the boundary for context?
  2. DEM Quality Evaluation
    • Resolution appropriate for your stream scale?
    • Artifacts (pits, flat areas, bridges, culverts)?
    • Vertical accuracy sufficient for subtle geomorphic features?
    • Do you need to condition the DEM (breach, fill sinks)?
  3. Stream Network Decisions
    • Using existing mapped streams vs. deriving from DEM?
    • If mapped: Are they accurate? Complete? At appropriate scale?
    • If derived: What flow accumulation threshold represents actual channels?
    • How do you handle intermittent vs. perennial streams?
  4. Valley Bottom Conceptualization
    • What defines “valley bottom” in your landscape?
    • Floodplain? Terrace? Active channel migration zone?
    • How wide should the valley be in different stream orders?

Phase 2: Geomorphic Analysis

Geomorphic Analysis

HydroDEM

toolbox

Creates a hydrologically conditioned DEM - foundation for flow analysis

→

Flow Direction

ArcGIS Pro

Creates flow direction raster (D8 or D-Infinity) - foundation for all flow analyses

→

Flow Accumulation

toolbox

Calculates upstream contributing area - used for stream network delineation

→

Slope

ArcGIS Pro

Gradient analysis - critical for identifying valley breaks and channel confinement

→

REM

toolbox

Relative Elevation Model - removes elevation trend to highlight floodplains and terraces

→

TPI

ArcGIS Pro

Topographic Position Index - identifies ridges, valleys, and flat areas

Phase 3: Valley Bottom Delineation

Valley Bottom Delineation

Stream Network Creation

ArcGIS Pro

Raster Calculator or Con tool to threshold flow accumulation - creates binary stream/non-stream raster

→

Euclidean Distance

ArcGIS Pro

Measures distance from any cell to nearest stream - helps define lateral valley extent

→

Raster Calculator

ArcGIS Pro

Combine slope, REM, distance, TPI using logical criteria - iterative refinement based on visual assessment

→

Raster to Polygon

ArcGIS Pro

Converts final valley bottom raster to vector - allows for manual editing and attribution

→

Manual Editing

ArcGIS Pro

Remove isolated pixels, adjust boundaries based on aerial imagery or field knowledge, add attributes

Phase 4: Confinement Analysis

Confinement Analysis

Valley Width Measurement

ArcGIS Pro

Transects perpendicular to stream centerline - calculate width at regular intervals

→

Confinement Ratio

Analysis

Valley width / Channel width - Confined (<4:1), Partly Confined (4-10:1), Unconfined (>10:1)

→

Lateral Confinement

ArcGIS Pro

Buffer analysis showing where valley margins constrain channel - identifies confined vs. unconfined reaches

Note

Valley Bottom Workflow Focus This workflow emphasizes the critical thinking required in Phase 1 before running any tools. The actual tools run are minimal - primarily Project Raster and data import tools. Phase 2 generates the geomorphic datasets (Flow Direction, Flow Accumulation, Slope, REM, TPI) that are then combined in Phase 3 to delineate valley bottoms. Phase 4 analyzes channel confinement within the delineated valley. Key Change: DetrendDEM is now called REM (Relative Elevation Model) to better reflect its purpose of showing relative topographic position.

Key Considerations ::: {.panel-tabset} Quality Control

Visual comparison with aerial imagery Field validation of key reaches Check for systematic errors Document assumptions and decisions

Iteration

Valley bottom delineation is iterative Adjust thresholds based on local conditions Test sensitivity to parameter changes Validate against known geomorphic features

Scale Considerations

DEM resolution affects feature detection Stream order influences valley width Adjust analysis parameters by stream size Consider multi-scale approaches
